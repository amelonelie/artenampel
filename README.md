ArtenAmpel is a hackathon project that brings structure to biodiversity data by visualizing IUCN Red List information.

Using a simple color system it shows whether a species is threatened and how severe the risk is. The project also provides a quick overview of trends in threatened species and the current state of biodiversity.

As an extra feature, ArtenAmpel displays the taxonomic classification of each species (order, family, genus) to add more context to the data.
